OPERATOR QUICK REFERENCE

Using OmniFleet AI

1 · Create a mission

Enter a command in Mission Control, select Generate plan, review the actions and checks, then approve or reject the proposal.

Go to Mission Control ↗
2 · Task from the map

Select an available vehicle, choose Place waypoint, and click inside the operating geofence. A proposal is created; it does not move until approved.

3 · Test sensors

Choose Place on map, set the virtual object's properties, click the map, then select Scan now. Review observations and provenance in the ledger.

Go to Sensor Intelligence ↗
4 · Review the blackbox

Select a vehicle, refresh telemetry, scrub the replay slider, or play/pause the captured samples.

Go to Blackbox Analytics ↗
5 · Exercise the swarm

Set the network mode and links, apply the policy, test a peer link, request status or broadcast an informational message. Detection proposals still require operator approval.

Go to Swarm Communications ↗

Simulation only. No controls connect to physical vehicles, radios, cameras or autopilots. Do not use for navigation or safety-critical decisions.
